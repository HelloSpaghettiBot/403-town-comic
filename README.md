# 403 Town Comic

Project workspace for the 403 Town Comic app.

## Main Project

The live app source is in `app/403-Town-Combined`.

## Setup

Install dependencies with pnpm:

```sh
cd app/403-Town-Combined
pnpm install
```

Build the project:

```sh
pnpm run build
```

## Repository Notes

This Git repository keeps source files, configuration, and lockfiles. Dependency folders, build output, packaged archives, deployment bundles, and local scratch files are ignored so GitHub stays clean and practical to use.
